# Seguridad

Un problema de seguridad **no va en un issue público**. Reportalo en privado desde la pestaña
*Security* del repo ([reportar una vulnerabilidad](https://github.com/EasyIndustry/3d-print-separator-tool/security/advisories/new)),
con qué versión, cómo reproducirlo y qué permite.

Se responde, se arregla en una versión nueva y se publica el aviso cuando la versión arreglada
está disponible, con crédito para quien lo reportó si lo quiere.

Se arregla sobre la última versión publicada. Si el problema está en un módulo vendorizado, se reporta en el repo de ese módulo
y se vuelve a vendorizar (ver [`POLITICA.md`](POLITICA.md)).
